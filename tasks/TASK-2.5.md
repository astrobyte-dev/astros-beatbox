## Validation

Run from `mcp` on Windows, using the repository's Node/npm versions. Quit the
normal rig first: the System UI check creates a temporary UDP 57110 conflict,
and the live checks require exclusive audio ports.

```powershell
npm ci
npm test
npm run typecheck
npx playwright install chromium
node browser-selftest.mjs
node studio-selftest.mjs
node p2-selftest.mjs
node system-selftest.mjs
node launcher-open-selftest.mjs
```

The launcher check intentionally opens the system's default browser. It requires
Windows Script Host and a desktop session. For real audio tests, first use System
to Quit the normal rig; never run these concurrently with another audio rig:

```powershell
node p2-selftest.mjs --live
node recording-live-selftest.mjs
node runtime-live-selftest.mjs
node system-live-selftest.mjs
```
